# 🐍 Python Çalışmalarım

Python öğrenme yolculuğumda yazdığım örnekler, alıştırmalar ve küçük projeler burada toplanıyor.

## 📂 İçindekiler

| Klasör / Dosya | İçerik |
| --- | --- |
| `PythonOperatörleri.py` | Operatörler üzerine örnekler |
| `PythondaKoşulİfadeler` | `if` / `elif` / `else` koşul ifadeleri |
| `PythondaDöngüler` | `for` ve `while` döngüleri |
| `PythondaFonksiyonlar` | Fonksiyon tanımlama ve kullanma |
| `PythondaNTP` | NTP çalışmaları |
| `Problems` | Çözdüğüm problemler (`Hareket.py`) |
| `Döviz ve ALtın` | Döviz/altın bildirim scripti (`doviz_bildirim.py`) ve nasıl yaptığımın notları |

## ▶️ Çalıştırma

```bash
python dosya_adi.py
```

> Python 3 yüklü olması yeterli. Bazı scriptler ek kütüphane isteyebilir; gerekiyorsa dosyanın başındaki `import` satırlarına bakıp `pip install` ile kurabilirsin.
